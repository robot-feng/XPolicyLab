## 2. 核心代码地图

| 文件 | 职责 | KnowAct 改动重点 |
|---|---|---|
| `model.py` | XPolicyLab 输入/输出适配、checkpoint 加载、环境状态表 | 复用 G05 obs/action 转换；每个 env 保存独立 `InferenceState`；校验回执序号 |
| `deploy.py` | RoboDojo rollout | 下发前 `replan_steps` 步；下一轮附加真实执行步数回执 |
| `G05/src/g05/models/g05/g05_policy.py` | G05 训练与生成编排 | `append_context`、`generate_text`、`generate_action` 和 native train 路由 |
| `G05/src/g05/models/g05/native_context.py` | 原生上下文操作 | 模态编码、追加、文本 AR、BAR16、执行前缀提交、训练 CE |
| `G05/src/g05/models/g05/g05_model_qwen35.py` | 原生 Qwen3.5 特征与 Forward | `encode_context_segment` / `forward_context`，复用 Vision、Proprio、MRoPE、GDN、Full Attention |
| `G05/src/g05/models/g05/inferencer.py` | XPL 原始 obs preprocess / postprocess | `infer_stream` 串接 `append_context → optional text → generate_action → decode` |
| `G05/src/g05/data/native_episodes.py` | Episode 历史采样与 Collate | 同 Episode 历史、执行前缀 hold-pad、context-only 标签、当前轮监督 |
| `G05/src/g05/data/mixture_lerobot_dataset.py` | 原 LeRobot 数据集 | 当前样本采样后附加 `native_history` |
| `G05/scripts/finetune.py` | 原训练器 | Native train Collate 接入；验证 DataLoader 当前仍是原单轮 Collate |
| `G05/src/g05/models/g05/helpers/mask_helper.py` | 原生 Attention / MRoPE | 完整与增量上下文布局保持一致 |
| `G05/src/g05/models/g05/qwen35/gated_deltanet.py` | GDN 循环与卷积状态 | 多 Token 增量计算需要继承历史卷积状态 |
| `G05/src/g05/tokenizer/interface/bar_builder.py` | BAR 序列布局 | 原生 BOS / block / EOS 结构，BAR16 固定布局 |
| `G05/src/g05/tokenizer/interface/vq_base.py` | 原生 ActionCodec 接口 | 原 Codec 编码、解码和动作结构约束 |

## 3. 训练数据流

```text
LeRobot current row
    │
    ├── 当前图像 / 当前状态 / 当前指令 / 当前动作 target
    │
    └── 同 Episode 历史索引（1..native_context_turns）
             │
             ├── 历史图像 / 状态 / 指令
             ├── 已执行动作前缀（native_replan_steps）
             └── hold-last padding 到原 Codec horizon

Native Episode Collate
    │
    ├── 历史轮次：context-only，labels 全部 -100
    └── 当前轮次：原生 G05 labels
             │
             ▼
每轮调用原 Processor / Vision / Proprio 编码
             │
             ▼
拼接 embedding、attention layout、MRoPE grids、labels
             │
             ▼
G05ModelQwen35.forward_context（一次完整因果序列计算）
             │
             ▼
原生 ARHelper.cal_ce_loss（原 CE）
```

当前实现按 Episode 分别做 B=1 前向，再对有效监督 Token 数加权汇总 loss。没有增加 memory encoder、memory loss 或专用 ICL head。

## 4. 推理数据流

```text
XPolicyLab observation
    │
    ▼
原版 G05 Adapter 的观测打包 / Processor
    │
    ▼
KnowAct Model._predict_chunks（按 env key 隔离）
    │
    ▼
PolicyInferencer.infer_stream
    │
    ├── policy.append_context（追加当前多模态观测）
    ├── optional policy.generate_text（共享同一个 InferenceState）
    └── policy.generate_action(action_source="ar")
             │
             ▼
原生 BAR16 → 原生 ActionCodec 完整解码
             │
             ▼
G05 Adapter 原有 action postprocess / robot action packing
             │
             ▼
环境只执行前 replan_steps 步
             │
             ▼
下一轮 observation + {plan, steps} execution receipt
             │
             ▼
将已确认执行前缀重新编码并追加到已提交上下文
```

## 5. InferenceState 的语义

状态来自原版 G05 的 `InferenceState`，并在 Native Context 路径中扩展使用。核心字段包括：

- `input_ids`：已经提交的逻辑 Token 序列，用于检查长度和重放。
- `attention_mask`：与已提交序列对应的注意力布局。
- `position_ids`：由原生 MRoPE / MaskHelper 计算。
- `kv_cache`：Full Attention KV、GDN recurrent state、卷积状态等原生计算缓存。
- `last_hidden`：下一次生成所需的末位置隐藏状态。
- `pending_action`：当前尚未收到执行回执的动作 proposal（仅保存重建已执行前缀所需数据）。
- `generated_ids` / `generated_texts`：本轮输出诊断信息。

`Context` 是信息来源，`Cache` 是计算状态。当前超出 `native_context_max_tokens` 会报错，不会静默丢弃历史；必要时必须显式 reset/replay。

## 6. 参数与结构

- 新增可训练模型参数：0。
- Backbone：沿用 G0.5 Qwen3.5 混合注意力。
- Vision Encoder / ProprioEmbedder：沿用原实现。
- LM Head：共享原生 LM Head。
- Language：普通 AR。
- Action：原生 ActionCodec + BAR16。
- Objective：原生 CE。
- Native Context 当前 AR-only，不支持 FM-only 或 AR+FM 联合生成。
