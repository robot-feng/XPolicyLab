# 00｜项目说明、范围与版本基线

## 1. 项目目标

KnowAct 是在 XPolicyLab 中独立注册的 G0.5 派生策略。当前研究目标是让同一个多模态自回归模型利用已发生的视觉、语言、机器人状态、动作计划和真实执行反馈，完成持续理解与动作生成。

当前设计坚持：

- 复用 G0.5 的 Qwen3.5 主干、Vision Encoder、ProprioEmbedder、Gated DeltaNet、Full Attention、MRoPE、ActionCodec、BARBuilder 和 LM Head。
- 不新增可训练 Memory Network、ICL Head、Mode Head 或独立 Action Expert。
- 使用原生 CE 训练；多轮历史只改变输入上下文与监督位置。
- 语言继续使用 Token-wise AR；动作默认使用原生 BAR16。
- 执行历史只记录已确认下发的命令前缀；真实测量状态仍由下一轮观测提供。
- 原版 `policy/G05` 作为对照组保持不变。

## 2. 仓库与源码基线

- XPolicyLab：用户上传的 XPolicyLab-main 源码快照。
- 快照标签：`4a9e3afd73b86a48c5db076f5cf9dbfbef1a180e`（来自此前集成记录；ZIP 无 `.git` 元数据，无法在本包内独立验证）。
- KnowAct：独立目录 `policy/KnowAct/`。
- Vendored G0.5：`policy/KnowAct/G05/`，作为 KnowAct 的模型源码运行副本；该目录是项目聚焦子集，部分上游 README 链接指向未随包提供的文档/实验目录，详见 `G05/VENDORED_SOURCE_NOTE.md`。
- 原版 G05：`policy/G05/`，不由本项目覆盖或修改。

### 为什么要独立 Python 环境

两个策略都使用顶层包名 `g05`。如果同一个 Python 进程先导入原版 G05，再导入 KnowAct vendored G05，`sys.modules` 可能复用错误路径下的模块。KnowAct Adapter 对此有路径保护，但正式运行仍应使用独立 policy-server 进程和独立环境。

## 3. 当前明确支持范围

当前 Native Context 经过验证的配置范围很窄，不能泛化成所有 G0.5 数据集都可用：

- Benchmark：RoboDojo。
- Embodiment / env config：`arx_x5`。
- Action type：`joint`。
- 当前观察：单个当前时刻观测，`obs_size=1`。
- 数据频率：`model_fps == fps`。
- 动作时间偏移：必须为 0。
- 历史动作：按执行步数取前缀，再使用 hold-last padding 恢复原始 Codec horizon。
- 预处理：已验证的 pointwise action normalization；不支持额外 action transforms、stepwise action normalization 或非 DummyActionFilter。
- 生成：AR-only，BAR16，固定 grouped action layout，`ar_block_num=0`。
- 部署：单环境状态隔离；批量环境按 env key 逐条执行正确性路径，再原子提交。

超出以上范围必须先增加独立适配与测试，不能仅通过 Hydra override 让它“运行起来”。

## 4. 当前不支持或尚未证明的能力

| 能力 | 当前状态 |
|---|---|
| 跨 Episode 示范 ICL | 数据管线尚未实现；现有历史采样只来自同一 Episode |
| 多轮验证集 | `finetune.py` 的验证 DataLoader 仍使用原单轮 Collate |
| FM Native Context | 不支持；Native Context 仅 AR |
| 任意 BAR block size | 不支持；训练/推理布局固定 BAR16 |
| 因果 ActionCodec / 部分解码执行 | 不支持；必须完整解码后再执行部分轨迹 |
| chunk 内异步打断 | 不支持；只在动作 chunk 边界接收回执和重新规划 |
| 自动上下文压缩 / eviction | 不支持；超出 token budget 直接报错 |
| 超越官方 G05 | 尚未通过真实权重、同预算、真实仿真对照证明 |

## 5. 版本原则

后续实验按“假设 → 最小改动 → 单元/集成回归 → matched ablation → 真实 benchmark”推进。只有实验显示原生机制不足，才允许增加新模型实体。当前优先工作是完善真实数据、预训练权重回归和评测，而不是扩充架构。
