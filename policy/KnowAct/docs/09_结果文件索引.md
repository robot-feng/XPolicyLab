# 09｜原始结果文件索引

`results/` 和 `G05/tests/results/` 保留 V5–V7 的原始日志与中间数据。历史文件不代表全部都是有效实验；尤其 `aborted_invalid_grip/` 是因动作规则轨迹不合法而中止的实验，不能纳入最终统计。

## 1. `results/`

| 文件 / 子目录 | 内容 | 使用注意 |
|---|---|---|
| `v6_final_regression_54.log` | V6 阶段 54 项 CPU 回归日志 | 历史记录 |
| `final_regression_v7_1.log` | 本次整理后的 73 项 CPU 回归日志 | 当前整理版测试记录 |
| `v7_final_regression.log` | V7 69 项测试日志 | 历史 V7 基线 |
| `v7_preflight.json` | 当时环境和资产存在性检查 | 不能替代正式权重加载 |
| `diagnosis11/22/33.json` | CE、teacher-forcing、free-running 诊断 | 小尺寸随机初始化模型 |
| `training.log` / `training_results.json` | V7 小模型训练轨迹和逐步指标 | 不代表预训练模型性能 |
| `v7_execution_test.log` | V7 执行回执 / 闭环协议诊断 | 模拟环境与小模型 |
| `v7_initial_regression.log` / `v7_last_checks.log` | V7 阶段中间回归记录 | 以最终回归日志为准 |
| `final_regression_v7_1.log` | 本次整理后73项测试结果 | 当前发布版 CPU 回归记录 |
| `icl_current_*.json` | 只看当前观测 ICL 对照 | 合成映射任务 |
| `icl_history_*.json` | 同 Episode 历史 ICL 对照 | 不等于跨 Episode 示范 ICL |
| `icl_mask_*.json` | 固定格式字段 mask 消融 | 当前没有证据支持默认启用 |
| `v7_icl_summary.csv` | ICL 结果汇总 | 结合报告解释，不能单独引用 |
| `codec_audit.json` / `.log` | 小配置 Codec / 规则码依赖诊断 | 不是正式预训练 Codec 经验统计 |
| `codec_pairs_*.npy` | 成对合成动作码 | 只适用于对应小配置实验 |
| `benchmark_manifest.example.json` | 当前 compare.py 生成的 FM-G05 / BAR16-KnowAct dry-run manifest 示例 | 示例路径为占位符，不是实际运行记录 |
| `benchmark_dry_run.example.log` | 当前 compare.py dry-run 命令输出 | 仅生成计划，没有启动仿真 |
| `preflight_development_container.json` | 本次整理环境的 preflight 快照 | Python 3.13、CPU、无正式资产；不是用户训练服务器状态 |
| `source_regression_v5.log` | V5 源码回归历史日志 | 历史记录 |
| `aborted_invalid_grip/` | 被中止的非法夹爪轨迹实验 | 必须排除 |

## 2. `G05/tests/results/`

保存 V5/V6 源码对照、精度测试、训练 smoke log 和 unit test log。它们用于定位源码问题，不是正式模型评测。

## 3. `G05/tests/` 中的脚本

| 脚本 | 用途 |
|---|---|
| `test_native_context.py` | 原生 G05 模型上下文、GDN、Mask、MRoPE、梯度和 cache 测试 |
| `test_native_policy.py` | G05Policy / ActionCodec / BAR / 文本与动作生成测试 |
| `test_v7.py` | executed-only history、hold-pad、训练数据与真实 grouped padding 测试 |
| `test_xpl_integration.py` | XPolicyLab Adapter + simulated IO 集成测试 |
| `test_comparison.py` | paired manifest / action source / paired score 测试 |
| `diagnose_v7.py` | 小尺寸训练与 teacher-forcing/free-running 诊断 |
| `experiment_v7.py` | 合成 held-out mapping ICL 诊断 |
| `codec_audit_v7.py` | 小型 FSQ 和 rule tokenizer 依赖诊断 |
| `experiment_native_policy.py` | 真实 G05Policy 小配置动作生成训练诊断 |
| `audit_action_codes.py` | 对外部导出的真实 paired action codes 做 BAR dependency audit |

## 4. 建议的新实验归档

不要覆盖历史 `results/`。每次正式实验单独建目录，记录 resolved config、source revision、asset hashes、训练日志、checkpoint、eval manifest、paired scores 和总结。
